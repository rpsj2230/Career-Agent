Automatic mode

Works through the applications the assistant could not finish: opens each, fills it, attaches its resume, presses Next and Submit, waits for the employer's confirmation, closes the tab, and goes on to the next. It stops and gives the application back to you, with the reason, at anything only you should do (a captcha, a password, a question it cannot answer, a page it does not trust). It only runs when Auto-Apply is on in Career Agent and the daily limit is not used up.

Applications waiting for you

Link to Career Agent (once) In Career Agent: Profile, "Browser extension", press Make a link code, copy it, and paste it here. After that the extension gets your latest data by itself.
No link? Paste the data file instead Profile: "Download fill data". Paste the file's text here. It will not update by itself.

It never types a password, a payment or an identity number, and never creates an account.
